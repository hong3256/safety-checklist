# 만천초등학교 안전보건 자체점검표

학교 현장에서 매월 쓰는 **안전보건관리 자체점검표**를 휴대폰·PC에서 바로 체크하고, 여러 명이 동시에 점검할 수 있게 만든 웹앱(PWA)입니다.

- 주소(공개 후): `https://hong3256.github.io/safety-checklist/`
- 구글 시트: 「만천초등학교 안전보건 자체점검표」와 실시간 연동

## 들어 있는 것

| 탭 | 문항 |
| --- | --- |
| 자체점검표(공통) | 28 |
| 1. 급식종사자 | 48 (환기방법 안내행 포함 49행) |
| 2. 경비업무 | 15 |
| 4. 시설관리 | 20 |
| 5. 미화업무 | 18 |
| 6. 학교보안관 | 13 |
| **합계** | **142문항** |

## 기능

- **점검 연월 선택** — 상단 제목 아래의 `2026년 / 12월` 드롭다운에서 연도(2025~2030)와 월(1~12)을 고르면, 각 탭의 문서 제목과 PDF 파일명이 `2026년 12월 안전보건관리 자체점검표`처럼 바로 바뀝니다. 고른 연월은 기기에 저장돼 다음에 열 때도 그대로입니다.
- **예 / 아니오 토글** — 누르면 `∨` 표시(예=연녹색, 아니오=연분홍), 다시 누르면 해제. 한 문항에 하나만 선택됩니다.
- **비고 직접 입력**, **점검일·점검자 입력** — `자체점검표(공통)` 탭에서 점검일을 지정하면 1~6 직종 탭의 점검일도 같은 날짜로 함께 바뀝니다. 직종 탭에서 직접 바꾸면 그 탭만 바뀝니다(점검자는 탭마다 따로 저장).
- **진행률** — 점검 완료 문항 수 / 전체 문항 수
- **공동 점검** — 잠금 없이 각자 맡은 탭을 편집. 바뀐 칸만 구글 시트에 저장되고 5초마다 다른 사람의 변경을 받아옵니다(입력 중인 칸은 덮어쓰지 않음).
- **🖨️ 인쇄** — A4 세로, 표 머리글 페이지마다 반복. 현재 탭 또는 전체 6개 탭.
- **📄 PDF 저장** — `.pdf` 파일로 바로 내려받기(현재 탭 / 전체). 파일명은 `2026년12월_만천초등학교_안전보건_자체점검표_{탭명}.pdf` 형식입니다.
- **오프라인 동작** — 한 번 열면 인터넷이 없어도 열리고, 입력은 기기에 저장됐다가 연결되면 시트로 올라갑니다.

## 처음 설정 (3단계)

### 1) GitHub Pages 켜기

저장소 → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `/ (root)` → **Save**.
1~2분 뒤 `https://hong3256.github.io/safety-checklist/` 로 열립니다.

### 2) 구글 시트에 Apps Script 붙이기

1. 시트에서 **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 `safety-apps-script.txt`(대화로 받은 파일) 내용을 그대로 붙여넣기
3. **저장 → 배포 → 새 배포 → 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 나온 `https://script.google.com/macros/s/.../exec` 주소 복사

### 3) 앱과 연결 (이미 내장됨)

웹 앱 주소는 `index.html`의 `DEFAULT_SYNC_URL`에 **기본값으로 심어 두었습니다**. 동료분들은 위 주소(`https://hong3256.github.io/safety-checklist/`)만 열면 설정 없이 배지가 `🟢 실시간 동기화`로 바뀝니다.

다른 시트·다른 배포로 바꾸려면 앱 오른쪽 위 **⚙️** → 주소 붙여넣기 → **저장**.
(브라우저에 저장된 주소가 내장 기본값보다 우선합니다. 기존 설치 기기는 서비스워커가 새 버전을 받은 뒤 두 번째 실행부터 반영됩니다.)
